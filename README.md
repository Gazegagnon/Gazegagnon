## À propos

💻 Passionné par le développement logiciel, les architectures backend et les pratiques DevOps, j'aime concevoir des applications robustes, maintenables et évolutives. Au fil de mes projets académiques et personnels, j'ai développé une approche orientée résolution de problèmes, en cherchant toujours à comprendre les besoins métiers avant d'apporter une solution technique.

Ce qui me distingue : je documente systématiquement les vraies difficultés rencontrées sur chaque projet, les causes profondes et les solutions retenues. Apprendre en profondeur plutôt qu'en surface.

> *Le code doit servir l'humain — pas l'inverse.*

---

## 🌟 Points forts

- 🚀 **Projets réalisés** : 7 applications full-stack couvrant web, logistique, pédagogie, Big Data et DevOps.
- 🏗️ ** Développement logiciel** : Conception d'applications complètes en appliquant les principes d'architecture modernes et les bonnes pratiques de développement.
- 🐳 **DevOps** : Mise en place de pipelines CI/CD avec GitHub Actions, Docker et Kubernetes pour automatiser les phases de test et de déploiement.
- 🧪 **Qualité logicielle** : Mise en œuvre de tests automatisés (PHPUnit, Django TestCase) afin de garantir la fiabilité et la maintenabilité des applications.
- 📚 **Apprentissage continu** : Veille technologique permanente et volonté constante d'explorer de nouveaux outils, frameworks et méthodologies.
- 🌱 **Engagement** : Toujours en quête d'apprentissage continu — chaque projet documente les vraies difficultés rencontrées et les leçons tirées.
- 🎓 **Formation** : Développement Web & Big Data — avec une forte orientation projet et une mise en pratique régulière des technologies étudiées.
- 🤝 **Esprit d'équipe** : Habitué à travailler sur des projets collaboratifs en utilisant Git, GitHub et les méthodes de développement modernes.
